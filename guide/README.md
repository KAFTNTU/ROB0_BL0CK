# Навчальна довідка ROB0 BL0CK

Відкрийте `guide/` через HTTP-сервер сайту. Довідка працює як статичні HTML, CSS, JavaScript та JSON і не потребує окремого сервера застосунку.

У `programs.json` зберігаються 14 навчальних програм, їх пояснення та XML. Файли `xml/*.xml` відповідають цим програмам. Зображення `images/01-*.png` — `images/14-*.png` отримані після імпорту відповідного XML у Blockly проєкту, а не намальовані вручну. SVG містять векторний експорт тих самих схем. `programs.zip` містить усі 14 XML.

Зображення `interface-reference.png` та `start-reference.png` взято з наданої автором методички. На стартовій сторінці використано схему інтерфейсу з поясненням відмінностей від поточної версії.

Розділ `#blocks` містить повний довідник: 106 типів із меню редактора, три варіанти умовного блоку та два допоміжні типи — разом 108 типів і 110 карток. Дані описів знаходяться в `blocks.json`, XML окремих блоків — у `blocks-xml/`, зображення — в `images/block-*.png`. Всі сім категорій мають окремі сторінки. Картки містять пояснення полів, приклад, важливі особливості та посилання на готові програми, де вони доречні. Дві заготовки без реалізації позначено явно.

Завантаження PNG і службові технічні підписи прибрано з інтерфейсу для учнів. Зображення зберігаються як ресурси сайту. Завантаження XML залишається доступним. Кастомні скролери зберігають нативну прокрутку клавіатурою та дотиком.

Приклади призначені для звичайного редактора й запуску зі сторінки браузера. Робота на фізичному роботі потребує перевірки напрямків моторів, портів, порогів датчиків і часу поворотів. Підтримка автономного виконання в пам’яті контролера не заявляється.

Перевірено імпорт усіх XML, єдину зв’язану конструкцію кожної програми, генерацію JavaScript, повний XML round trip та 17 сценаріїв із підставними моторними, часовими, сенсорними й дисплейними функціями. Це програмні тести, не випробування обладнання.
